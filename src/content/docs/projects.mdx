LocoLabo is a set of small, independent projects that share one question: how much useful AI can run on hardware people actually own. Start with the question you have.

- **I want to run a model.** [LocoLLM](/projects/#build) builds the models, [LocoBanco](/projects/#measure) tells you what fits, [LocoPuente](/projects/#run) puts it to work.
- **I want to know what old hardware can do.** Start with [LocoFósil](/projects/#measure).
- **I want to know if it is any good.** [LocoMusa](/projects/#measure) measures thinking-partner quality.
